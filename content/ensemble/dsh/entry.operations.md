## Records on this path

The DSH plugin owns the private archive, its versions, and generated views. Use `ensemble_work`, `ensemble_learn`, `ensemble_read`, and `ensemble_upload`; do not create a workspace record directory, choose storage paths, hand-edit generated views, or run Git to update the archive. Native tools still own agents, messages, tasks, and model selection.

**Start and resume.** Call `ensemble_read` with `{"kind":"context"}` to obtain the bound project, current permissions and `read_revision`. If the owner has not configured the archive, bound this workspace, or granted access, report that specific gap. Do not invent an identity or fall back to another records mechanism. On resumption, read the invocation and checkpoint, inspect uncertain operation receipts, and reconcile native members without replaying earlier external actions.

**Write one business action.** Work and learning commands use `{action, payload, expected_revision, operation_id}`. Use the returned archive revision and retain the same operation key only when retrying identical business content. A successful receipt identifies accepted storage, not verified truth. On a revision conflict, reread and make a new decision with a new key. On an unknown outcome, query the receipt before taking dependent action. A member name, role or statement that the user agreed never grants authority.

**Coordinate a complete outcome.** Open an invocation with required coverage and criteria. Plan attempts, then bind the real native identities returned by the native tools. Save full artifacts and submit contributions; the Lead records a decision for the exact contribution version. Set the candidate, record what each check actually observed, and resolve conflicting checks explicitly. Completion is refused when required coverage or current critical evidence is missing. A native task becoming inactive or completed is not an acceptance decision.

**Preserve complete material.** Short text can be supplied to `put_artifact`. For larger text or binary content, begin an upload, send byte chunks with offsets and digests, seal it, and reference its returned handle in `put_artifact`. Sealing does not itself archive the content. Read original bytes and exact object versions through `ensemble_read`; follow every partial result's cursor or byte offset until completeness is established. Do not treat a summary as the original or discard limitations to fit a response.

**Review and learn.** Use `ensemble_learn` for coaching, reflection proposals, assigned independent reviews, publication, amendments, lessons and applications. Reviews apply to the exact draft version and the author cannot supply an independent review. An unresolved blocking review remains blocking even if another reviewer approves. Publication does not prove transfer: record the next task's application, limitations and counterexamples separately. Correct or retire misleading guidance while preserving its earlier account.

**Read generated state.** [`STATE-TEMPLATE.md`](STATE-TEMPLATE.md) describes checkpoint fields; [`EVOLUTION-TEMPLATE.md`](EVOLUTION-TEMPLATE.md) supplies reflection questions. Read checkpoint, reading, history and lesson projections with `ensemble_read`, rather than editing them. Fetch fixed revisions when making judgments. Permissions are checked again on historical reads and pagination; stop if access is revoked.

**Select native capabilities.** Consult allowed native routes and any applied environment preferences. Preferences are recommendations, not authorization or permission to change the Lead's model. Keep provider/model/effort in the native selection fields; distinguish requested selection, returned identity, and actual model-request evidence. Record unavailable evidence as unknown instead of filling it from a model's self-description.
