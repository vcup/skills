## Records on this path

The installed DSH plugin stores project coordination and complete material in a private, versioned archive outside the source workspace. User management enters through the authenticated Client or `ensemble-archive` CLI; models use scoped domain tools. Binding and current authorization are required even when a tool is visible.

- **Working state:** `ensemble_work` records the invocation, attempts, artifacts, contributions, judgments and checks. `ensemble_read` returns context, checkpoint and exact historical versions.
- **Complete material:** `ensemble_upload` accepts bounded byte chunks; sealed material becomes an artifact only when a work command archives it. Original bytes, summaries and generated views remain distinct.
- **Learning:** `ensemble_learn` records coaching, independent review, publication, amendments, lessons and application evidence. Saving, accepting, verifying and publishing are separate states.
- **Recovery:** current receipts identify committed operations after interruption; native agent and task state must be reconciled separately. Missing configuration, access or evidence remains a visible gap.

[`STATE-TEMPLATE.md`](STATE-TEMPLATE.md) is a description of the generated checkpoint, not a file to maintain. [`EVOLUTION-TEMPLATE.md`](EVOLUTION-TEMPLATE.md) guides reflection content. See [`SKILL.md`](SKILL.md#records-on-this-path) for the command discipline and native capability rules.
