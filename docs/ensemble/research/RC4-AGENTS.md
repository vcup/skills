# RC4-AGENTS：原生代理接入的发行源码核验

本文整理对[原生代理接入](../NATIVE-AGENTS.md)的历史静态核验，保留初查发现与 Lead 更正。比较基线为旧开发 snapshot `39163dd30f703a79079e2d2446545cff3c453738` → 正式 `dsh-v0.2.2-rc.4`（`3f321d32bfe382212a8ed8785c1d47a5a300aa23`）。旧提交是 master 的 rc.3 同步提交，**不是正式 rc.3 tag**；两提交非线性，旧独有 608、新独有 8。以下结论描述发行提交的现状或两个端点的差异，不能逐条归因于“rc.4 新功能”。正式 rc.3 → rc.4 的代理、Team、workflow 实现没有变化，详见[发布基线](RC4-BASELINE.md)。

核验方法：`git diff -- packages/subagent packages/team packages/workflow` 加定点读文件；未安装、未运行测试。下文 §2–§5 指原生代理接入文档的对应章节，引用标签名用于保留当时的引用修订记录。

## A. 仍成立的行为

1. **整树通信**：`send_message` / `list_agents` 仍按 live caller 的树解析，`interrupt_agent` 仍要求祖先权限。[控制工具 L44–79](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent-control/src/index.ts#L44-L79)、[中断校验 L120–154](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent-control/src/index.ts#L120-L154)。
2. **fresh 共享任务**：Team 默认关闭；claim/release/reassign 使用 CAS；普通修改由 owner 或 Lead 执行，重派由 Lead 执行。[Team 说明](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/team/agent-team/README.md)、[任务执行 L128–151](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/team/agent-team/src/task-board.ts#L128-L151)、[所有权与重派 L188–201](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/team/agent-team/src/task-board.ts#L188-L201)。
3. **选型开关与默认值**：标准 spawn 实例 `modelSelection`、`modelDiscovery` 均为 `true`，fork 实例未显式开启这两项；插件默认 `false`。[标准 preset L99–116](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/bundle/web-app/presets/standard.patch.yml#L99-L116)、[插件默认值 L49–50](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent/README.md#L49-L50)。
4. **effort 语义**：provider/model 成对；effort 需要同时给出这两个字段；显式 route 省略 effort 会清除继承 effort；无 Session policy 时只允许父路由。[模型选择 L101–150](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent/src/model-selection.ts#L101-L150)。
5. **preset**：`agentPreset` / `allowedAgentPresets` / `agent_preset` 仍在；仅 in-process spawn 支持，fork 与外部 backend 拒绝。[preset 约定 L53–69](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent/README.md#L53-L69)。
6. **workflow 参数**：`agent()` options 闭集仍为 `label/phase/schema/provider/model`；`effort` / `isolation` / `agentType` 仍属 deferred；host 仍将 provider/model 直接放入 `agentOptions`。[options L33–35](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/workflow/workflow-ptc/src/runtime.ts#L33-L35)、[参数校验 L253–257](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/workflow/workflow-ptc/src/runtime.ts#L253-L257)、[host L200–216](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/workflow/workflow-ptc/src/host.ts#L200-L216)。

## B. 发行基线下的文档与实施约束

这些是相对旧开发 snapshot 的约束；“删除/改为”不表示正式 rc.3 → rc.4 的发布变化。原稿把 B2/B3 称作“原正文错误码断言失效”，Lead 确认原正式设计没有依赖这些具体码，应作为实施版本约束保留。

1. **版本与引用 SHA**：当时正文的 `0.2.2-rc.3` 基线需改为 `0.2.2-rc.4`；`[version]`、`[spawn]`、`[fork]`、`[control]`、`[messages]`、`[team]`、`[tasks]`、`[selection-tool]`、`[standard]`、`[fork-selection-test]`、`[selection]`、`[registry]`、`[workflow-host]`、`[workflow-runtime]` 应引用 `3f321d32bfe382212a8ed8785c1d47a5a300aa23`，否则仍指向旧开发源码。历史研究自身仍保留原基线。
2. **§2/§3 的错误类型与具体码**：相对开发 snapshot，发行提交中的选型、preset、工具参数及上下文校验不能再依赖原 `ToolArgsError` / `ToolContextUnavailableError` / `SubagentError` 分支的 `MODEL_SELECTION_DISABLED`、`PRESET_SELECTION_DISABLED`、`PRESET_NOT_ALLOWED`、`MODEL_ROUTE_NOT_ALLOWED`、`LLM_PROVIDER_NOT_FOUND`、`PROVIDER_CHANGED`、`INVALID_DEPTH` 细分码；相关分支使用普通 `Error` / `TypeError`。`SubagentErrorCode` 类型不导出，`SubagentError.code` 类型为 `string`；`tool-subagent/src/index.ts` 不再含旧的那些 throw 分支。拒绝行为仍在，实施时应按发行真实返回和拒绝事实验收；`[messages]` / `[control]` 中关于 `ToolContextUnavailableError` 的旧描述也不能照搬。**不能把这些局部差异概括成全部原生失败都没有 code**：`SubagentError` 及若干 code 仍存在，例如 manager 的 `UNAUTHORIZED`。[错误类 L10–15](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/subagent/src/error.ts#L10-L15)、[工具执行](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/tool-subagent/src/index.ts)、[manager](https://github.com/deepseek-ai/deepseek-harness/blob/3f321d32bfe382212a8ed8785c1d47a5a300aa23/packages/subagent/subagent/src/manager.ts)。
